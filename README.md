# Ксюнечка

Сайт-знакомство с Ксюшей для арендодателей. Для просмотра на компьютере откройте `index.html` в браузере. Фото и видео находятся в папке `assets`.

## Бесплатная публикация на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `ksyusha`.
2. Распакуйте архив и загрузите его **содержимое** в корень репозитория через **Add file → Upload files**. В корне должны оказаться `index.html`, `styles.css`, `site.js` и папка `assets`. Если ваш файловый менеджер показывает скрытые файлы, можно также загрузить `.nojekyll`. Сохраните загруженные файлы в ветке `main` через **Commit changes**.
3. В настройках репозитория откройте **Settings → Pages**. В поле **Source** выберите **Deploy from a branch**, укажите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. Когда публикация завершится, на той же странице появится кнопка **Visit site**. Откройте её и скопируйте адрес сайта для арендодателей.

Публичный репозиторий и опубликованный сайт доступны всем, у кого есть ссылка. [Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
